The Monad publication uses a small semantic vocabulary rather than a collection of unrelated decorative boxes. Each component communicates a specific type of engineering information.

<Decision title="Keep canonical documents renderer-independent">
  Canonical repository documents remain readable as ordinary Markdown. The publication projection may enrich recognized conventions into MDX components, but the source does not depend on Fumadocs.
</Decision>

<Constraint title="Do not encode meaning with color alone">
  Every component includes an explicit textual label. Color only reinforces the component's semantic role.
</Constraint>
